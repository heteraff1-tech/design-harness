# Сборка через Figma MCP

1. По [входному брифу](../../input/HANDOFF_FROM_RESEARCH.md) определи URL файла, ID целевых и эталонных узлов, размеры, режимы и состояния. Проверь доступные операции MCP и права чтения и записи.
2. Прочитай целевое дерево, используемые варианты, коллекции Variables и Text Styles. При наличии Code Connect сверь сопоставления, не меняя библиотечные связи.
3. Подготовь план фрейма. Для каждого контейнера укажи направление, выравнивание, Hug, Fill или Fixed. Для управляемых свойств сопоставь [семантическое имя](../../rules/tokens-summary.md), коллекцию и режим. Сопоставь структуру и переходы с паттернами сценария.
4. Собери один фрейм с библиотечными экземплярами. Привяжи поддерживаемые свойства к переменным, а текст оформляй стилями. Точечно проверяй значения в целевых режимах.
5. Перечитай узлы после записи и проверь дерево, экземпляры, привязки, режимы, переносы и размеры. Если операция прервалась, сначала перечитай фактическое состояние и продолжай с существующих узлов.
6. Собери оставшиеся размеры и состояния по проверенной структуре. Запусти [design-audit](../design-audit/SKILL.md).

При отсутствии прав записи подготовь план по узлам и перечисли недоступные операции. При отсутствии нужной переменной зафиксируй роль и узел, чтобы согласовать привязку. Если доступен только скриншот, используй его для композиции и пометь привязки как непроверенные.

## Точечная сверка токенов

1. Сначала определи нужные роли и режимы по фрейму, [краткому списку](../../rules/tokens-summary.md) и [каталогу Figma](../../rules/figma-styles.md).
2. Для сверки конкретных значений открой [полный DTCG](../../rules/tokens-dtcg.json) через JSON-фильтр. Выводи только нужные поля. Например, `jq '.color.dark.bg.page."$value"' rules/tokens-dtcg.json` из корня проекта. Для размеров используй общие ветки `radius`, `size` и `font`.
3. При расхождении укажи путь токена, режим, значение в Figma и значение в DTCG. Уточни, какое определение актуально, прежде чем обновлять привязку.

## Результат

Ссылки на целевые фреймы, перечень состояний и размеров, режимы Variables, переиспользованные компоненты и открытые вопросы.
