# Аудит макета

1. Открой целевые фреймы, исходный сценарий и релевантные правила из [карты](../../index.md). Начни отдельный проход с фактического дерева и визуального представления, сверяя оба источника.
2. Проверь все затронутые фреймы на соответствие следующим критериям.

| Критерий | Проверка |
| --- | --- |
| Структура | Имена слоёв, Auto Layout, корректный Hug/Fill/Fixed и отсутствие случайного переполнения. |
| Компоненты | Библиотечные экземпляры, нужные варианты, сохранённые связи и соответствие Code Connect при наличии. |
| Токены | Семантические Variables и режимы, Text Styles, управляемые свойства без сырых значений. |
| UX | Основное действие, ритм, понятные тексты и состояния. Пройди [10 эвристик Нильсена](../../rules/ux-heuristics.md#10-эвристик-нильсена) по ключевому сценарию. Для интерфейсов здоровья сверяйся с [паттернами сценариев](../../rules/ux-patterns.md). |
| Доступность | Контраст в каждом целевом режиме, видимый фокус, логичный порядок обхода, размеры зон тапа и статус помимо цвета. |
| Адаптация | Крайние целевые размеры, длинные строки, реальные данные и изменение высоты контейнеров. |

3. Запиши каждое отклонение с прямой ссылкой на узел, наблюдением, ожидаемым результатом и статусом. Отметь отдельно проверки, для которых не хватило данных. Зафиксируй блокеры передачи, если затронут основной сценарий, доступность или обязательная привязка.
4. Исправь отклонения в пределах задачи и перепроверь затронутые фреймы. Передай ссылки, состояния, режимы и открытые пункты.

## Проверки в репозитории приложения

Передай ожидаемые условия для Stylelint по сырым значениям и сценарии для Playwright по размерам, состояниям и визуальным регрессиям. Укажи применимые автоматические проверки доступности и ручные проверки фокуса и порядка обхода. Отметь фактический статус выполнения каждой проверки.
