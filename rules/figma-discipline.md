# Дисциплина Figma

## Структура

- Организуй рабочие области по назначению. Используй страницы Tokens, Components и Screens в новом файле, а в существующем сохрани принятую структуру.
- Называй фреймы по сценарию и состоянию, например `Booking / Empty`. Называй слои по функции, например `Appointment details` и `Submit booking`.
- Собирай контейнеры через Auto Layout. Задавай Hug, Fill или Fixed по ожидаемому поведению. Абсолютную позицию используй для намеренных наложений.
- Переиспользуй библиотечные экземпляры и свойства вариантов. При наличии Code Connect сохраняй связь с сопоставленным компонентом.

## Значения и оформление

- Сверяй [токены DTCG](tokens-dtcg.json) с локальными Variables из [каталога Figma](figma-styles.md). Выбирай цветовую ветку, соответствующую режиму экрана.
- Используй Color Variables для заливок и обводок и числовые Variables для поддерживаемых размеров, отступов и скруглений. При переносе dimension в числовую переменную проверь единицу и правило преобразования.
- Бери типографику из Text Styles. Цвет текста привязывай отдельно к семантической переменной.
- Проверяй коллекцию, режим и фактическую привязку. Совпадение цвета или размера само по себе недостаточно.
- Используй брендовый акцент для действий и малых акцентов. Сохраняй нейтральный фон экрана.
- Применяй error, warning и success по статусу. Используй согласованный токен видимого фокуса и проверяй контраст на выбранной поверхности.
- Отмечай отсутствующие роли, стили и свойства с узлом и назначением. Согласуй расширение системы до внесения новых значений.

## Прототипы Make

- Разбери прототип на сценарии и компоненты. При переносе восстанови экземпляры, Auto Layout, Variables, Text Styles и режимы.
- Проверь дерево, привязки, состояния и адаптацию в редактируемом макете. Передай его через [аудит](../.skills/design-audit/SKILL.md).
