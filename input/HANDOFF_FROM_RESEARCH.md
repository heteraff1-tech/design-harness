# Входной бриф из исследования

Этап исследования заполняет этот шаблон перед передачей в дизайн. Один бриф описывает одну задачу. Поля в угловых скобках замени данными задачи.

| Поле | Что заполнить |
| --- | --- |
| ID и ревизия | `<Стабильный ID задачи и ревизия брифа>` |
| Цель | `<Что пользователь должен суметь сделать и как измерить результат>` |
| Аудитория и контекст | `<Кто выполняет сценарий, где и при каких ограничениях>` |
| Источники | `<Ссылки на материалы, наблюдения и обоснования решений>` |
| Объём | `<Сценарии, состояния и ограничения задачи>` |
| Платформа | `<Целевые размеры, режимы темы, язык и требования доступности>` |
| Figma | `<Целевые и эталонные фреймы, библиотека, если применимо>` |
| Открытые вопросы | `<Какие допущения нужно проверить и какие решения ещё не приняты>` |

## Сценарии и критерии приёмки

Опиши исходное состояние, действие пользователя и ожидаемый результат. Добавь ошибки, пустые состояния и восстановление там, где они применимы. Привяжи каждый критерий к сценарию или выводу исследования.

| ID | Сценарий и состояние | Наблюдаемый критерий приёмки |
| --- | --- | --- |
| `<ID>` | `<Сценарий и состояние>` | `<Что должно происходить>` |
